# coding-test

Java 코딩테스트 학습 저장소입니다.

## 학습 방식

* 하루 1문제
* 20~30분 학습
* Java 사용
* 쉬운 문제부터 정확하게 해결
* 문제를 읽고 직접 로직을 생각한 뒤 구현
* 막히면 힌트를 참고하고 다시 직접 작성
* 틀리거나 어려웠던 문제는 재풀이

## 학습 범위

* 조건문 / 반복문
* 배열 / 문자열
* List / Map / Set
* 정렬
* 완전탐색
* 스택 / 큐
* DFS / BFS
* 이분 탐색
* 그리디
* DP

## 목표

정답 코드를 외우는 것이 아니라
문제의 조건을 분석하고 Java 코드로 직접 구현할 수 있는 능력을 기르는 것을 목표로 합니다.
